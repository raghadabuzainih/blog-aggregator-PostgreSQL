# Blog Aggregator CLI

A command-line blog aggregation tool built with **TypeScript**, **Node.js**, and **PostgreSQL**.  
The application fetches RSS feeds, parses XML content, and stores blog data in a structured database.

## Features

- CLI-based command system
- User registration & authentication
- PostgreSQL integration using **Drizzle ORM**
- RSS feed fetching with custom User-Agent
- XML parsing using **fast-xml-parser**
- Modular architecture (commands, DB layer, RSS services)

## Tech Stack

- TypeScript
- Node.js
- PostgreSQL
- Drizzle ORM
- fast-xml-parser
